# 👛 HissaClub

> A transparent group expense and milestone pooling platform built for seamless collective collections with zero awkward follow-ups.

🌐 **Live Demo:** [https://hissaclub.vercel.app/](https://hissaclub.vercel.app/)

---

## 📌 Overview

**HissaClub** simplifies group expense management for events, trips, hostel dues, and shared milestones. Instead of tracking payments in scattered chat threads or spreadsheets, organizers can launch a dedicated money pool in under two minutes, distribute a single link, collect payment slips securely, and manage verification privately.

Contributors do not need to download an application or create an account. They can open the link in any mobile browser, view payment details (JazzCash, EasyPaisa, or Bank IBAN), and submit their proof of payment directly.

---

## ✨ Key Features

- **No Sign-Up Needed:** Friends and contributors access the shared pool link instantly via web browser.
- **Flexible Split Configurations:** Supports equal per-person shares or open-amount contributions.
- **Privacy-First Verification:** Payment screenshots and transaction details remain private between the contributor and organizer.
- **PIN-Protected Admin Dashboard:** Organizers manage approvals, view receipts, and audit totals behind a confidential 4-digit PIN.
- **1-Click WhatsApp Reminders:** Automated nudge messages with pre-filled pool links for contributors with pending payments.
- **Bilingual Guide System:** Interactive "How It Works" documentation with instant English and Urdu language toggling.
- **Local Payment Support:** Tailored for Pakistani payment methods including JazzCash, EasyPaisa, SadaPay, and local Bank transfers.
- **Auditable Ledger:** Clean, printable audit summaries for transparent collective spending records.

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js (v18 or higher) installed on your system.

### Installation

1. **Clone the repository: Start the development server:**
   git clone [https://github.com/sana-javed-04/hissaclub.git](https://github.com/sana-javed-04/hissaclub.git)
   cd hissaclub

2. **Install dependencies:**
   npm install

3. **Set up Environment Variables:**
   Create a .env file in the root directory:
   VITE_SUPABASE_URL=your_supabase_project_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

4. **Start the development server:**
   npm run dev
   Open http://localhost:8080 in your browser.
